# Changelog

## [1.4.2] - 2026-06-03

- Rendering fixes.
- Added tooltip for shield cooldowns, based on the one originally present when the mod depended on Shield Lib.
- Different shields now have different cooldowns, with plated shields now having double the cooldown of their base variant.

## [1.4.1] - 2026-05-26

- NeoForge port.
- Improved compatibility with Reliable Recipe Viewer.
- Fixed crash when blocking items with Soulbound.
- Allow shields from other mods to be repaired with Patch Kits.
- General code cleanup.

## [1.4.0] - 2026-03-24

- Port to 26.1
- Dropped dependency on Shield Lib/Architectury API/MidnightLib

## [1.3.4] - 2026-02-26

- Hotfixed tags not being loaded in production.

## [1.3.3] - 2026-02-26

- Removed Honeycomb from Copper Shield recipe as 1.21.9+ established Copper Tools do not oxidize.
- Upgraded RRV support to 6.5.0
- Bumped dependencies.

## [1.3.2] - 2026-01-12

- Replaced recipe viewer compatibility with RRV, an updated fork of EIV with additional features.

## [1.3.1] - 2025-12-07

- Fixed an issue with entrypoints on Fabric.

## [1.3.0] - 2025-12-07

- Updated for Minecraft 1.21.8
- Now supports Fabric and NeoForge thanks to Shield Lib becoming multiplatform on 1.21.8. An update to 1.21.10 will follow once Shield Lib ports.
- Now supports EIV rather than EMI, as EMI is not available on 1.21.8.

## [1.2.5] - 2025-03-15

- Fixed issue with loot tables being too common.
- Reduced attack time for Evokers summoned via the evokering enchantment to make it more difficult to dodge.
- Fixed issue with missing translations for banner shields.
- Added partial EMI compatability, no default recipes yet.

## [1.2.4] - 2025-02-04

- Added Ukrainian translations - thank you @StarmanMine142
- Fixed recipe conditionals.
- Fixed issue where mod would not load on dedicated servers.

## [1.2.3] - 2025-01-31

- Added various compatibility fixes for More Shield Variants.
- Added enchantment descriptions, thanks @mpustovoi!
- Added Russian translations, thanks @mpustovoi!

## [1.2.2] - 2025-01-06

- Fixes anvil crafting recipe bug for diamond shields.

## [1.2.1] - 2025-01-06

- Fix fabric.mod.json issue.

## [1.2.0] - 2025-01-06

- Migrated to stonecutter build system.
- Fixed issue with recipes not working in certain worlds.
- Fixed issue where treasure-only enchantments were available in the enchantment table.
- Updated metadata to link to the wiki.

## [1.1.0] - 2025-01-06

- Fix enchantment issues.

## [1.0.0] - 2025-01-05

Initial release! Check out the mod description for more information!
